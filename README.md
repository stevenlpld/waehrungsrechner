# SAP Bewerbungs-FAQ (Python Konsolenprojekt)

Dieses kleine Python-Tool ist Teil meines Vorbereitungsprojekts für eine Bewerbung als (Junior) Software Engineer im SAP BTP AI Team.  
Es bietet ein textbasiertes Menü mit häufigen Fragen rund um SAP, Software Engineering und meine eigenen Stärken.

## 🔧 Funktionen

- Konsolenmenü mit mehreren Auswahlmöglichkeiten
- Endlosschleife mit Möglichkeit zum Beenden (`Option 4`)
- Erste Übung mit `if/else`, `while`, `input` und Formatierung
- Humorvoller Touch 😄

## 📋 Menü-Optionen

1. Was ist SAP BTP?  
2. Was macht ein Software Engineer?  
3. Was sind deine Stärken?  
4. Beenden
